# farol-releases

Source AltStore/SideStore + releases públicas do app **Farol** (GTD pessoal).

- `apps.json` — manifesto da Source (schema oficial AltStore), servido via GitHub Pages.
- Releases desta página — cada uma com o `.ipa` sem assinatura correspondente.

Repositório público dedicado porque o repo principal ([gtd-leobons-dev/gtd](https://github.com/gtd-leobons-dev/gtd)) é privado — GitHub Pages/Releases de repo privado não ficam publicamente acessíveis sem autenticação, e o AltStore/SideStore não envia credenciais.

## Cadastrar no AltStore/SideStore

Adicione esta URL como Source: `https://gtd-leobons-dev.github.io/farol-releases/apps.json`

Detalhes: [specs/008-altstore-source/](https://github.com/gtd-leobons-dev/gtd/tree/master/specs/008-altstore-source) no repo principal.
